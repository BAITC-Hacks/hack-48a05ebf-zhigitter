# FAQ-бот на 5 вопросов — команда Zhigitter

Трек 03 «LLM-приложения», задание 01. Чат в терминале, который отвечает на пять
заранее известных вопросов про репетицию, а на всё остальное честно говорит «не знаю».
Python 3.8+, только стандартная библиотека, устанавливать ничего не нужно.

## Запуск

```bash
python bot.py                   # интерактивный чат
python bot.py "какой трек"      # разовый вопрос (код возврата 2, если ответа нет)
python test_bot.py              # смоук-тесты
```

## Пример сессии

```
FAQ-бот репетиции HackAlem AI. Команда Zhigitter.
Знаю ответы на 5 вопросов:
  1. Когда проходит репетиция, какие сроки и дедлайн?
  2. Кто в команде, какой состав участников?
  3. Какой у нас трек и что за задание?
  4. Как сдавать решение, куда заливать код?
  5. Какие призы и награды за репетицию?
Команды: «помощь» — показать вопросы, «выход» — закончить.

вы> какие призы
бот> Призов нет — это репетиция, а не основной HackAlem AI.

вы> сколько времени осталось
бот> Репетиция идёт 21 сентября с 18:00 до 19:00. Решение нужно загрузить до окончания хакатона кнопкой «Сдать решение» на странице задания.

вы> кто в команде
бот> Команда Zhigitter: Асиреталы Кайратов (один участник).

вы> а ты умеешь писать стихи
бот> Не знаю. Я отвечаю только на эти вопросы:
  1. Когда проходит репетиция, какие сроки и дедлайн?
  2. Кто в команде, какой состав участников?
  3. Какой у нас трек и что за задание?
  4. Как сдавать решение, куда заливать код?
  5. Какие призы и награды за репетицию?

вы> выход
пока!
```

## Как устроено

`faq.txt` — пять блоков `Q:` / `A:` плюс необязательная строка `K:` со словами-синонимами.
Запрос приводится к нижнему регистру, `ё → е`, выкидываются стоп-слова, а слова режутся
до четырёх букв — так «призы», «призов» и «приз» считаются одним словом без морфологических
библиотек. Дальше считается доля слов запроса, найденных в паре: попадание в вопрос — вес 1.0,
в синонимы — 0.8, в текст ответа — 0.4. Если лучший результат ниже порога 0.34, бот отвечает
«не знаю» и показывает список своих вопросов. Эмбеддинги и RAG не используются: по условию
задания хватает совпадения по ключевым словам. Флаг `--debug` печатает скор рядом с ответом.

## Что получилось

Бот отвечает и на исходные формулировки, и на перефразировки («куда заливать код», «когда дедлайн»,
«кто участвует»), а посторонние вопросы отсекает. `test_bot.py` прогоняет 18 таких случаев — все зелёные.
Новый вопрос добавляется дописыванием блока в `faq.txt`, код трогать не нужно.
